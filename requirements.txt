# ============================================================
# INSTALLATION NOTES
# ============================================================
# 1. Create virtual environment: python -m venv KAI
# 2. Activate venv: KAI\Scripts\activate (Windows)
# 3. Install: pip install -r requirements.txt
# 4. Additional setup:
#    - For OCR: Download Tesseract from https://github.com/UB-Mannheim/tesseract/wiki
#    - For Spotify: Create app at https://developer.spotify.com/dashboard
#    - For APIs: Get keys from Gemini, OpenAI, and/or Claude dashboards
# 5. Create .env file with API keys
# 6. Edit config.yaml for preferences
# 7. Run: python main.py
